# 🤖 بوت مشاريع مستقل — تشغيل دائم ومجاني

بوت يتابع مشاريع **البرمجة والذكاء الاصطناعي** على مستقل، ويرسل المشاريع الأقل منافسة (أقل من 10 عروض) إلى قناة تليجرام.

يعمل تلقائيًا على **GitHub Actions** — مجاني بالكامل، بدون سيرفر وبدون كارت ائتمان، ولا يحتاج جهازك مفتوحًا.

---

## ⚠️ أول خطوة: أمان المفاتيح

التوكن ومفتاح ScraperAPI كانوا مكتوبين داخل الكود القديم. لازم قبل أي شيء:

1. افتح **@BotFather** → `/mybots` → اختر البوت → `API Token` → **Revoke current token** واحصل على توكن جديد.
2. من لوحة **ScraperAPI** أعد توليد المفتاح (Regenerate).
3. لا تكتب المفاتيح داخل الكود نهائيًا — الكود الجديد يقرأها من GitHub Secrets.


## 🚀 خطوات التشغيل

### 1) إنشاء المستودع

1. افتح [github.com/new](https://github.com/new) وأنشئ مستودعًا جديدًا باسم `mostaql-bot`.
2. اجعله **Public** (المستودعات العامة لها دقائق تشغيل غير محدودة في Actions، والخاصة محدودة بـ 2000 دقيقة شهريًا).
3. ارفع ملفات المشروع عبر زر **Add file → Upload files**، أو من الطرفية:

```bash
cd mostaql-bot
git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/USERNAME/mostaql-bot.git
git push -u origin main
```

> ملاحظة: كون المستودع Public **لا يكشف** مفاتيحك، لأنها محفوظة في Secrets وليست في الكود.

### 2) إضافة المفاتيح (Secrets)

من صفحة المستودع: **Settings → Secrets and variables → Actions → New repository secret**

| الاسم | القيمة |
|---|---|
| `TELEGRAM_TOKEN` | التوكن الجديد من BotFather |
| `TELEGRAM_CHAT_ID` | معرّف القناة (مثال: `-1002566956165`) |
| `SCRAPER_KEY` | مفتاح ScraperAPI (اختياري) |

### 3) التشغيل

من تبويب **Actions** → اختر `Mostaql Bot` → اضغط **Run workflow** للتجربة الفورية.

بعدها سيعمل تلقائيًا كل 3 ساعات.

## ⏱️ وقت التشغيل — كل 15 دقيقة

البوت مضبوط حالياً على **كل 15 دقيقة** في `.github/workflows/bot.yml`:

```yaml
- cron: "*/15 * * * *"
```

| التكرار | القيمة |
|---|---|
| كل 15 دقيقة (الحالي) | `*/15 * * * *` |
| كل 30 دقيقة | `*/30 * * * *` |
| كل ساعة | `0 * * * *` |
| كل 3 ساعات | `0 */3 * * *` |

التوقيت بـ **UTC** (توقيت القاهرة = UTC + 3 صيفاً / + 2 شتاءً)، لكن مع التكرار كل 15 دقيقة لن تحتاج لحساب التوقيت أصلاً.

### ⚠️ ملاحظة مهمة عن دقة الجدولة

جدولة GitHub **ليست مضمونة بالدقيقة**. أقل فاصل مسموح به هو 5 دقائق، لكن في أوقات الضغط قد تتأخر الجولة 5 إلى 20 دقيقة، وقد تُلغى جولة أحياناً وتُدمج مع التي بعدها. النتيجة العملية: معظم الجولات ستأتي كل 15–20 دقيقة، وبعضها قد يتأخر أكثر.

### 🔁 الحل لو التأخير أزعجك

يوجد ملف بديل جاهز: `.github/workflows/bot-hourly.yml`

يعمل **مرة كل ساعة**، وبداخله **4 جولات متتالية بفاصل 15 دقيقة** — الفاصل هنا مضبوط داخل بايثون نفسه، فلا يتأثر بتأخير GitHub.

للتفعيل:
1. في `bot.yml` احذف أو علّق سطري `schedule` و `cron`.
2. في `bot-hourly.yml` أزل التعليق عن:
```yaml
schedule:
  - cron: "0 * * * *"
```
3. ارفع التغيير.

## 📉 ضبط الاستهلاك مع التكرار السريع

مع التشغيل كل 15 دقيقة (96 جولة يومياً) ضبطت `PAGES` على **1** لأن المشاريع الجديدة تظهر في الصفحة الأولى دائماً، والصفحات التالية تكرار بلا فائدة.

**بخصوص ScraperAPI:** الخطة المجانية 1000 طلب شهرياً فقط، و96 جولة يومياً تعني ~2880 طلباً شهرياً. لذلك:

- الكود يجرب **الجلب المباشر أولاً** ولا يستهلك رصيداً إلا عند فشله.
- لو أردت ألّا يُستهلك الرصيد نهائياً: **لا تضف** `SCRAPER_KEY` في Secrets — البوت سيعتمد على الجلب المباشر فقط، ويتخطى الجولة بهدوء لو فشلت.
- لو الجلب المباشر فشل باستمرار، خفّف التكرار إلى كل 30 دقيقة أو ساعة حتى يكفي الرصيد.

**وبخصوص مستقل نفسه:** 96 طلباً يومياً من نفس عنوان IP معقول، لكن لا تزد عن ذلك حتى لا يُحظر وصولك.

**دقائق GitHub:** الجولة الواحدة تستغرق ~1 دقيقة، أي ~2900 دقيقة شهرياً — وهذا يتجاوز حد 2000 دقيقة للمستودعات الخاصة. **لذلك يجب أن يكون المستودع Public** (دقائقه غير محدودة).

## 🔑 أهم التعديلات عن النسخة القديمة

| النسخة القديمة | النسخة الجديدة |
|---|---|
| `while True` لا نهائي (يقف بقفل Colab) | جولة واحدة، والجدولة من GitHub |
| المفاتيح مكتوبة في الكود | متغيرات بيئة + Secrets |
| `sqlite` مؤقت يضيع بعد كل جلسة | `sent.json` يُحفظ في المستودع |
| كل الطلبات عبر ScraperAPI | محاولة مباشرة أولًا، وScraperAPI احتياطي |
| `"ai"` و `"ml"` تطابق داخل أي كلمة | مطابقة ككلمة كاملة فقط |
| روابط نسبية أحيانًا | روابط كاملة دائمًا |

## 🧪 التشغيل محليًا للتجربة

```bash
pip install -r requirements.txt

export TELEGRAM_TOKEN="التوكن"
export TELEGRAM_CHAT_ID="-100..."
export SCRAPER_KEY="المفتاح"

python bot.py
```

على ويندوز استخدم `set` بدل `export`.

## 🛠️ حل المشاكل

| المشكلة | الحل |
|---|---|
| لا تصل رسائل | تأكد أن البوت **Admin** في القناة، وأن `CHAT_ID` يبدأ بـ `-100` |
| `chat not found` | أعد إضافة البوت للقناة وتحقق من المعرّف |
| كل الصفحات تفشل | انتهى رصيد ScraperAPI أو تغيّر شكل صفحة مستقل |
| لا مشاريع جديدة | طبيعي — الكل مُرسل سابقًا، أو لا توجد مشاريع أقل من 10 عروض |
| توقفت الجدولة | GitHub يوقف الجدولة في المستودعات الخاملة 60 يومًا — ادخل واضغط Run workflow |
